# ByAzen

Тихий браузер в браузере: тёмный минималистичный интерфейс, продуманный поиск и аккуратная
библиотека. Всё работает локально — данные не покидают устройство.

## Возможности

- **Умная адресная строка.** Понимает запросы, домены и внутренние маршруты `byazen://`.
  Подсказки: недавние запросы, история, закладки, быстрые команды (`>`) и статьи Википедии.
- **Поиск с мгновенными ответами.** Внутренняя страница результатов собирает карточку-ответ и
  статьи из Википедии, плюс обсуждения Hacker News. Переход в DuckDuckGo, Google, Яндекс или Brave
  в один клик; поисковик по умолчанию задаётся в настройках.
- **Вкладки, история, закладки.** Настоящая многозадачность, локальная история на 500 записей,
  библиотека закладок с поиском и экспорт данных в JSON.
- **Оформление.** Четыре фона, четыре акцентных цвета, переключатель зерна. Всё сохраняется.
- **Погода в строке состояния.** По геолокации (по желанию) или по выбранному вручную городу.
- **Клавиатура.** `/` — поиск, `T` — новая вкладка, `W` — закрыть, `B` — закладки, `H` — история,
  `,` — настройки, `?` — шпаргалка. `Ctrl/⌘ + L` и `Alt + ←/→` тоже работают.
- **Адаптивность.** Десктоп и мобильный — с переработанной компоновкой, а не просто сжатием.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # типы + production-сборка в dist/
npm run preview  # предпросмотр сборки
```

Стек: React 19, TypeScript, Vite. Шрифты и иконки упакованы локально, без внешних CDN.

## Заметки

- Встроенный просмотр сайтов работает, когда сайт разрешает `iframe`. Для почты, соцсетей и
  крупных сервисов ByAzen показывает аккуратную заглушку с кнопкой «Открыть сайт» — это правило
  самого сайта, а не ограничение браузера.
- Поисковые подсказки, Википедия, Hacker News и погода используют публичные открытые API.
- Настройки, закладки, история и вкладки хранятся в `localStorage` и `sessionStorage` браузера.
