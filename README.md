# ByAzen

Тихий браузер в браузере: тёмный минималистичный интерфейс, продуманный поиск и аккуратная
библиотека. Всё работает локально — данные не покидают устройство.

## Возможности

- **Умная адресная строка.** Понимает запросы, домены и внутренние маршруты `byazen://`.
  Подсказки: недавние запросы, история, закладки, быстрые команды (`>`) и статьи Википедии.
- **Поиск с мгновенными ответами.** Внутренняя страница результатов собирает карточку-ответ и
  статьи из Википедии, плюс обсуждения Hacker News. Переход в DuckDuckGo, Google, Яндекс или Brave
  в один клик; поисковик по умолчанию задаётся в настройках.
- **Вкладки, история, закладки.** Настоящая многозадачность, локальная история на 500 записей,
  библиотека закладок с поиском и экспорт данных в JSON.
- **Оформление.** Четыре фона, четыре акцентных цвета, переключатель зерна. Всё сохраняется.
- **Погода в строке состояния.** По геолокации (по желанию) или по выбранному вручную городу.
- **Клавиатура.** `/` — поиск, `T` — новая вкладка, `W` — закрыть, `B` — закладки, `H` — история,
  `,` — настройки, `?` — шпаргалка. `Ctrl/⌘ + L` и `Alt + ←/→` тоже работают.
- **Адаптивность.** Десктоп и мобильный — с переработанной компоновкой, а не просто сжатием.

## Windows

Готовое приложение — **`dist-win/ByAzen.exe`**, один файл, без установки.

- **Требования.** Windows 10 (1803+) или Windows 11, 64-битная. Window — это Microsoft Edge
  WebView2, он уже стоит в Windows 11 и в свежих сборках Windows 10. Если его нет, ByAzen
  скажет об этом при запуске и подскажет, где взять Evergreen Bootstrapper.
- **Как запустить.** Скачать `ByAzen.exe` и открыть двойным щелчком. Ничего не устанавливается,
  рядом с файлом ничего не создаётся: настройки WebView2 живут в `%LOCALAPPDATA%\ByAzen`, а
  закладки, история и оформление — во внутреннем хранилище приложения.
- **Что внутри.** Интерфейс целиком лежит в exe как ресурс (2 МБ): при старте приложение поднимает
  небольшой сервер на `127.0.0.1` и отдаёт ему страницу, чтобы `localStorage`, `sessionStorage` и
  `fetch` работали ровно так же, как в вебе. Ссылки «Открыть сайт» передаются браузеру по
  умолчанию через этот же сервер.
- **Честная граница.** ByAzen.exe — это интерфейс ByAzen с его поиском, библиотекой и настройками.
  Произвольные сайты он не рендерит: внешние страницы открываются в браузере по умолчанию.
- **SmartScreen.** Файл собран без сертификата подписи кода, поэтому Windows может показать
  «Windows protected your PC» → «More info» → «Run anyway». Это ожидаемо для локально собранного
  exe.
- **Если вместо интерфейса чёрное окно.** ByAzen сам пробует несколько путей: WebView2, затем
  WebView2 с другим режимом отрисовки, затем отдельное окно Microsoft Edge в режиме приложения.
  Всё, что происходит при запуске, пишется в `%LOCALAPPDATA%\ByAzen\byazen.log`. Принудительно
  выбрать режим можно флагами: `ByAzen.exe --browser` (сразу окно браузера), `--gpu` или
  `--software` (режим отрисовки). Горячая клавиша `Ctrl+Alt+R` перезапускает движок, не закрывая
  приложение.

Собрать самому (Linux/macOS, без Visual Studio):

```bash
pip install ziglang pillow   # кросс-компилятор и рендер иконки
npm install
npm run build:win            # dist-desktop/ + dist-win/ByAzen.exe
npm run verify:win           # проверка PE, ресурсов и импортов
npm run test:http            # тесты локального сервера на настоящих сокетах
```

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # типы + production-сборка в dist/
npm run preview  # предпросмотр сборки
```

Стек: React 19, TypeScript, Vite. Шрифты и иконки упакованы локально, без внешних CDN.
Нативная оболочка для Windows — C без зависимостей и `zig cc`.

## Заметки

- Встроенный просмотр сайтов работает, когда сайт разрешает `iframe`. Для почты, соцсетей и
  крупных сервисов ByAzen показывает аккуратную заглушку с кнопкой «Открыть сайт» — это правило
  самого сайта, а не ограничение браузера.
- Поисковые подсказки, Википедия, Hacker News и погода используют публичные открытые API.
- Настройки, закладки, история и вкладки хранятся в `localStorage` и `sessionStorage` браузера.
- В `ByAzen.exe` используется официальный `WebView2Loader.dll` из Microsoft WebView2 SDK
  (`native/WebView2Loader.dll`, лицензия рядом). Он загружается из папки WebView2 Runtime, а если
  её нет — распаковывается в `%LOCALAPPDATA%\ByAzen`.
